# Word Raider

A simple command-line word guessing game written in Python.

## Features

- Randomly selects a word from a word list
- Gives the player 6 attempts
- Checks correct and misplaced letters
- Tracks incorrect letters

## Concepts Practiced

- `while` loops
- `for` loops
- `if` statements
- Lists
- File handling
- String methods
- `random.choice()`
- User input

## How to Run

```bash
python main.py
